# ハズレの記憶

**その期待、本当に必要ですか？**

パチンコ・パチスロをやめたい人が、衝動を感じたときに過去の自分の言葉や格言を読んで立ち止まるためのアプリです。記録はブラウザ（端末）の中だけに保存し、外部へ送信しません。

- アプリ：https://kacchan-lab.github.io/hazure-no-kioku/
- サポート：https://kacchan-lab.github.io/hazure-no-kioku/legal/support.html
- 利用規約：https://kacchan-lab.github.io/hazure-no-kioku/legal/terms.html
- プライバシーポリシー：https://kacchan-lab.github.io/hazure-no-kioku/legal/privacy.html

このリポジトリは公開用です。ルートにあるファイル（`index.html`、`_expo/`、`assets/` など）は、Expo版のソースから `npm run build:web` で作ったものをコピーしています。直接編集しないでください。`legal/` は規約・サポートページです。
