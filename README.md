# ハズレの記憶

**その期待、本当に必要ですか？**

パチンコ・パチスロをやめたい人が、過去の後悔や冷静な判断を思い出すための、スマートフォン向け行動支援Webアプリです。

## 起動

外部API・ログイン・追加の実行時ライブラリは不要です。HTML/CSS/JavaScriptの静的ファイルで動作します。

```sh
cd /workspace/hazure-no-kioku
python -m http.server 8000 --bind 127.0.0.1
```

ローカルで `http://127.0.0.1:8000` を開きます。JavaScriptモジュールを使うため、ファイルを直接開く代わりにHTTPサーバーで起動してください。GitHub Pagesは、このリポジトリのルートを公開元に設定すれば配信できます。GitHub Pagesの設定・公開はリポジトリ管理者が行ってください。

## 使い方

1. 打ちたい気持ちを0〜10で選び、「パチンコを考えてしまった」を押します。押した日時と強さが保存されます。
2. 音のない短いオリジナル演出（約5秒、必ず「ハズレ」：0〜1.5秒はリーチ開始、1.5〜3.5秒は図柄が動いて徐々に停止、3.5〜5秒は「ハズレ」を大きく表示）の後、自分の過去の言葉またはオリジナル格言が表示されます。演出はスキップできます。「設定・データ」でOFFにでき、端末の「動きを減らす」設定も尊重します。音声は常にOFFです。実在機種の素材、当たり、復活、点滅、効果音はありません。
3. 帰宅・10分の休憩・散歩・趣味や勉強・信頼できる人への連絡から、次の行動を選びます。「打たない勇者」へのリンクもあります。
4. 衝動をやり過ごしたら「今日は打たずに済んだ」を押します。言葉を見るだけでは成功に数えません。同じ衝動の成功は一度だけです。回数は自己申告であり、禁パチ日数ではありません。
5. 「自分の言葉」ではお気に入り、追加・編集・削除ができます（自分の言葉のみ編集・削除可能）。初期メッセージは40個：自分の過去の言葉4個、独自の格言36個。直前と同じ言葉は連続表示しません。最大1000個、1個120文字までです。
6. 「振り返り」で衝動・自己申告の回数、端末の現地時刻による日付ごとの記録、自分の言葉を確認できます。

## データと注意事項

- 記録・言葉・お気に入り・演出設定を、このブラウザのlocalStorageに保存します。外部送信しません。リンク先へ移動した場合、そのサイトの扱いに従います。
- **ブラウザのデータ削除、端末の変更、公開URLの変更で記録が消えたり、別の保存領域になったりします。** プライベートモードでも保存を維持できない場合があります。定期的にJSONをエクスポートしてください。
- JSONには自分で入力した言葉と衝動の日時が含まれます。安全な場所で管理してください。本名・メールアドレス・資産額・損失額を入力する必要はありません。初期データにこれらの個人情報はありません。
- インポートは現在のデータを置き換えます（確認あり）。形式、文字数、数値、重複ID、参照を検証し、不正なデータは反映しません。ファイルは5MB以内です。全データ削除も確認が必要で、初期状態に戻ります。
- 保存に失敗した操作は反映せず、画面に通知します。破損した保存データは読み込み時に自動で上書きせず、エクスポートで元の内容を退避できます。
- アプリは治療や専門的な支援の代わりではありません。つらい場合は信頼できる人や専門の相談先を頼ってください。
- リロードすると実行中の衝動の画面は閉じます。保存済み記録は残りますが、過去の記録に後から成功を加算する機能はありません。

## 詳細な振り返り分析（開発用デモ）

PLUS紹介画面の「表示状態を試す」でPLUSを選ぶと、分析を確認できます。無料の振り返り画面からもデモ紹介へ移動できます。FREE・購入確認中・確認失敗では分析を表示しません。表示切り替えは購入権限ではなく、保存しない開発用状態です。

直近7日・30日は端末の現地時刻で今日を含む暦日として集計し、現在時刻より未来の記録は除外します。衝動を感じた回数、打たずに済んだ自己申告の回数、成功率と日別グラフ・数値表を表示します。

成功率は「期間内の成功自己申告の回数 ÷ 期間内の衝動の記録回数 × 100」です。日数の割合ではなく、自己申告に基づく記録の割合です。自己申告の回数は衝動を記録した日で集計します。既存データに自己申告した日時は保存されていません。自己申告がない記録を実際に打ったと断定しません。記録0件では成功率を「—」と表示します。記録のない日は状況不明であり、成功日として数えません。少ない記録でも件数と記録のある日数を明示し、長期的な傾向とは扱いません。

分析は既存のlocalStorageを読み取るだけで、保存形式・データを書き換えません。読み込みエラー時は0件や0%に置き換えず、分析できない旨を表示します。30日グラフは横スクロールに対応し、日別の数値表でも確認できます。

`js/analysis.mjs`は純粋な集計、`js/analysis-ui.mjs`は表示、`js/plus-access.mjs`は開発用アクセス判定を担当します。UIは注入したアクセス確認インターフェースを通して表示を判断します。将来はこれをサーバー側の認証・購入権限確認に置き換え、サーバー側PLUS処理でも権限を検証する必要があります。現在のローカルデモ判定は購入の証拠やコピー防止ではありません。Stripe・Supabaseは未接続です。

## 回避額の記録と資産形成試算（開発用PLUSデモ）

PLUS紹介の表示状態をPLUSにすると利用できます。購入済みではありません。FREE・購入確認中・確認失敗では非表示になり、再読み込みでFREEに戻ります。保存操作でもアクセス確認インターフェースを使いますが、これは開発用デモであり、将来はサーバーで購入権限を検証する必要があります。

回避額は本人が任意で入力する推計値で、実際の貯金額・利益ではありません。入力日・0以上の整数金額・任意メモを記録し、編集・確認付き削除ができます。1件100万円、累計1億円、最大5000件、メモ120文字まで。入力日は1900年以降・今日以前とし、不正な日付、負数、小数、極端な金額を拒否します。累計・今月の回避額と件数、今月を含む直近12か月の月別グラフを表示します。古い記録も累計に含みます。

保存先は `hazure-no-kioku-money-v1` で、既存の `hazure-no-kioku-v1` は変更しません。設定画面の従来のJSONや無料版の全データ削除には回避額を含めません。回避額専用JSONのエクスポート・検証付きインポート・回避額のみの全削除を用意しています。個別バックアップの場合は両方のJSONが必要です。一括バックアップも利用できます。インポートは回避額だけを置き換えます（5MB以内、確認あり）。破損データは自動で上書きせず、そのまま書き出して退避できます。

試算は一括投資（追加積立なし）と毎月一定額の積立（初期元本なし）を明確に分けます。年利0〜10%、期間1〜30年。一括の仮定額は1億円、毎月の仮定額は100万円まで。累計を一括の仮定にコピーする操作は任意で、実際に投資したことにはなりません。条件・結果は保存しません。

- 一括：元本 × (1 + 年利) ^ 年数
- 積立：年利と等価な月利 `r = (1 + 年利)^(1/12) - 1`、月数 `n = 年数 × 12`。月末入金と仮定し、毎月額 × `((1+r)^n - 1) / r`。年利0%では毎月額 × 月数。
- 元本は一括の入力額、または毎月額 × 月数。仮定の運用益は仮定の合計 − 元本。円表示は四捨五入します。

税金・手数料・物価変動は考慮せず、一定利回りの仮定に基づく参考値です。将来の運用成果を保証しません。回避額を投資済みとは扱いません。

詳細分析の成功率も調査済みです。既存データは各衝動1件に `success` の真偽値1個を持ち、同じ対象で重複加算しません。分析も各衝動に最大1件の成功を数えるため、有効な既存形式では100%を超えません。別形式の成功配列や曖昧な対応関係を推測して変換していません。

## 自分専用の行動プラン（開発用PLUSデモ）

PLUSデモで代替行動を最大10件（各1〜120文字）登録できます。編集・確認付き削除・「上へ」「下へ」の並び替えに対応します。自分へのメッセージは任意で240文字まで保存できます。空欄を保存するとメッセージを解除します。

「10分間の行動プランを見る」で、最初の1分に立ち止まり、次の8分で登録した代替行動から一つを選び、最後の1分に気持ちを確認する目安を表示します。未登録なら散歩・音楽・運動・家族との会話などの例を表示します。例は自動で保存しません。利用は任意で、10分で衝動が収まることを保証しません。タイマー・達成判定はなく、途中で閉じても記録や成功回数は変わりません。

PLUSデモを選択した状態では、無料版の結果画面からも「自分の10分プランを見る」を開けます。この対処画面には価格や購入案内を表示しません。FREE・購入確認中・確認失敗では専用の管理・表示を隠します。編集・入出力の操作でも共通のアクセス確認インターフェースを使います。現在は開発用デモであり、本物の購入権限ではありません。

保存キーは `hazure-no-kioku-plan-v1`。無料版・回避額の既存保存領域と形式を変更しません。行動プラン専用JSONのエクスポート・検証付きインポート（100KB以内）・専用の全削除に対応します。インポートはプランのみを置き換え、件数・文字数・ID・専用形式を検証します。破損した内容は勝手に上書きせず、元のJSONを退避できます。設定画面の一括バックアップで3領域をまとめられます。個別方式の場合はFREE・回避額・行動プランの3つのJSONを保管してください。

一括バックアップを実装しました。形式と復元時の注意は `docs/unified-backup-design.md` に記載しています。


## FREE・PLUS一括バックアップ

設定・データの「FREE・PLUS一括バックアップ」はFREEでも利用できます。FREEの言葉・お気に入り・衝動記録・設定、回避額、行動プランを専用JSON v1にまとめます。購入権限・PLUSデモ状態・認証情報・秘密鍵・試算の一時入力は含みません。バックアップを編集してもPLUS権限は得られません。従来の個別JSONも維持しています。

復元は専用形式・32MB以内。3領域をすべて検証し、件数と上書き対象を表示して確認を求めます。現在の内容へ追加するのではなく、3領域を置き換えます。ほかのタブを閉じ、先に現在のデータを書き出してください。成功後は再読み込みし、デモ状態はFREEになります。

localStorageの複数キー更新は原子的ではありません。元データと新データを含む復元ジャーナルを先に保存するため、通常の保存より追加容量が必要です。ジャーナルを保存できなければデータ更新前に止めます。途中失敗では元の内容へ戻し、回復まで失敗したら情報を保持して編集を停止します。再起動時はアプリの通常読み込みより先に回復します。対応ブラウザではWeb Locksで同じ版のタブ間の復元処理も直列化します。

回復が完了しない場合は、ほかのタブを閉じ、同一サイトの保存データを消さずにブラウザの空き容量・保存設定を確認し、「未完了の復元を回復する」を使ってください。回復情報が破損した場合は自動削除しません。ブラウザ自体のデータ削除・故障まで防げるわけではないため、ダウンロードしたJSONを別途安全に保管してください。

`js/bootstrap.mjs`が起動前の回復、`js/backup.mjs`が形式検証・書き出し・復元、`js/backup-ui.mjs`が画面と編集停止を担当します。既存のFREE・PLUS機能の本体と保存形式は変更していません。
